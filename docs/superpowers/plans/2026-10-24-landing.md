# Лендинг «Пульт директора» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать одностраничный лендинг «Пульт директора» одним файлом `index.html`, который за десять секунд объясняет, что это, для кого и зачем, и ведёт к контакту.

**Architecture:** Один статический файл, стили в `<style>`, без JS. Страница из секций `header.hero`, `section#problem`, `section#modules`, `section#security`, `section#contact`, все внутри `main`. Цвета и отступы через CSS-переменные в `:root`.

**Tech Stack:** HTML5, CSS3, системный шрифт. Проверка: grep и браузер Playwright.

**Spec:** `docs/superpowers/specs/2026-10-24-landing-design.md`

## Global Constraints

- Один файл `index.html` прямо в `StartUp/landing`, стили внутри.
- Никаких внешних библиотек, шрифтов, картинок, скриптов, аналитики и любых `http://`/`https://` в файле, кроме отсутствия ссылок вообще (ссылка Telegram — `#`).
- Только русский язык, обращение на «вы», тон деловой и простой, без слов «ИИ», «нейросеть», жаргона. «1С» допустима.
- Светлая тема, один акцентный цвет, достаточный контраст текста.
- Нормально выглядит на ширине 375 px, без горизонтальной прокрутки.
- Заглушки контактов: Telegram `href="#"` с пометкой «замените на свой ник»; телефон текстом `+375 XX XXX-XX-XX`, без ссылки `tel:`.
- Никаких выдуманных цифр, отзывов, клиентов; слов «готовое ядро», «сертифицировано», «проверено», «соответствует закону», «абсолютно защищено» нет.
- Все меры безопасности в будущем времени. `<title>`: «Пульт директора».
- Страницу не публикуем и ничего не устанавливаем.

## Review Focus

- Очень длинное слово или ряд цифр в карточке на 320 px: текст переносится, прокрутки нет.
- Масштаб текста 200 %: блоки не перекрываются.
- Отключённые стили или печать: содержимое читаемо по порядку.
- Клик по `#`-кнопке: страница не прыгает в неожиданное место и не показывает 404.
- Тёмная тема системы: текст не становится невидимым (тема задана явно светлой через `color-scheme: light`).

## File Structure

- Create: `index.html` — вся страница. Файл небольшой, разделять нечего.

- [ ] **Step 1: Проверка** — grep: в файле ровно четыре `class="card"` в `#modules`, два `class="tag"`; есть фразы «три клика», «в Беларуси»; нет слов «готовое ядро», «сертифицировано», «проверено», «соответствует закону», «абсолютно».
